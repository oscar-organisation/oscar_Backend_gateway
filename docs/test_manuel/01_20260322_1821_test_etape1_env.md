# Test Manuel - Étape 1 : Infrastructure & Environnements

**Date de validation :** 22-03-2026 18:21
**Composant visé :** Backend / Fichiers d'environnement (`.env.dev`)

## 🎯 Objectif du test
Vérifier manuellement que le fichier d'environnement `.env.dev` contenant les clés secrètes est correctement formaté. Il ne doit pas faire planter Docker de manière silencieuse (espaces cachés, mauvais jeu de caractères).

## 📝 Prérequis
- Avoir Docker d'installé et démarré sur la machine.
- Le fichier `backend/env/.env.dev` doit exister avec la configuration `LIVEKIT_KEYS`.

## 🛠️ Exécution pas-à-pas
1. Ouvrir le terminal (`PowerShell`).
2. Se déplacer dans le bon répertoire :
   ```powershell
   cd c:\PROJET-HETIC\PROJET-fin-etude\OSCAR\Code\V1\backend\env
   ```
3. Exécuter le script de test :
   ```powershell
   .\verify_env.ps1
   ```

## ✅ Comportement et Résultat Attendu
Le script va forcer Docker à lancer un nano-système (Alpine) auquel on greffe le `.env.dev`. 
- Si la console affiche "✅ TEST REUSSI : .env.dev est parfaitement formaté et prêt", l'étape 1 est bonne.

## ❌ Comment débugger en cas d'erreur
Si l'erreur `docker: Error response from daemon` ou un texte rouge apparaît :
1. Ouvrir `.env.dev`.
2. S'assurer de la présence stricte des guillemets anglais `" "` autour de la valeur : `LIVEKIT_KEYS="devkey: devsecret"`.
3. Supprimer les espaces inséparables.
